# Early learning experiments

`sampling_fft.py` and `sampling_and_adc.ipynb` are the original workspace files,
moved here without changing their contents. They explore sampling, FFT and ADC
quantization and are retained as learning history.

They are not the validated portfolio demo. Run the repository-root command
`python 1_demo_audio/code/run_demo.py` for the original audio experiment.
The notebook-driven pipeline is documented in `2_downsample/README.md`.

The notebook requires a Jupyter/IPython environment; this is optional and is not
included in the runtime dependencies for the main demo.
