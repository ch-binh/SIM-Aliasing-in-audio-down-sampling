What happens when we drop samples from a piano note?¶

A real sampled A6 piano note, not a single sine wave. We compare a 48 kHz working input with two 8 kHz outputs. The original three-tone experiment remains unchanged.

Source: Lawrence Fritts, University of Iowa Musical Instrument Samples, distributed as 39221__Piano.ff.A6.wav in Pimoroni's Piano-HAT collection. See the bundled source license and attribution. The source is stereo PCM16 at 44.1 kHz; mono conversion and filtered resampling prepare the 48 kHz input. No extra tones are added.

def read_wav(path):
    with wave.open(str(path), "rb") as f:
        assert f.getsampwidth() == 2 and f.getcomptype() == "NONE"
        rate, channels = f.getframerate(), f.getnchannels()
        data = np.frombuffer(f.readframes(f.getnframes()), dtype="<i2").copy()
    return rate, data.reshape(-1, channels).astype(float).mean(axis=1) / 32768
def save_wav(path, x, fs):
    assert np.max(np.abs(x)) < 1, "Clipping would invalidate comparison"
    pcm = np.rint(x * 32767).astype("<i2")
    with wave.open(str(path), "wb") as f:
        f.setparams((1, 2, fs, len(pcm), "NONE", "not compressed"))
        f.writeframes(pcm.tobytes())
    return read_wav(path)[1]
def listen(x, rate):
    display(Audio(x, rate=rate, normalize=False))

1. Listen to the input¶

A piano key has a fundamental plus harmonics, an attack and a decaying envelope. A6 is nominally 1760 Hz. Its upper harmonics can exceed the new 4 kHz Nyquist limit even though the fundamental does not.

The source conversion uses SciPy's resample_poly, which already includes an anti-alias filter. That preparation is distinct from the intentionally unsafe sample dropping below. A single shared gain leaves headroom; we never normalize each result independently.

In [2]:
source_rate, source = read_wav(INPUT / "piano_A6_source.wav")
gcd = math.gcd(source_rate, FS)
prepared = resample_poly(source, FS // gcd, source_rate // gcd)
# Trim at most five samples so both branches have exactly equal durations.
prepared = prepared[:len(prepared) // FACTOR * FACTOR]
shared_gain = 0.8 / np.max(np.abs(prepared))
x = save_wav(INPUT / "piano_48khz.wav", prepared * shared_gain, FS)
print(f"Source: {source_rate} Hz; working input: {FS} Hz; duration: {len(x)/FS:.4f} s")
listen(x, FS)

2. Keep one sample, skip five¶

Play the retained samples at 8 kHz. Duration stays the same; this is not a slow-motion effect. Harmonics above 4 kHz can fold into the remaining band and alter the timbre. The size of the audible difference depends on this particular note, your playback device and your hearing.

$$ y[m] = x[6m] $$

3–4. Inspect the saved input and output¶

All FFTs read the saved WAV data. We use the same 0.05–0.55 s section and a Hann window because a decaying piano note is not a coherent stationary test tone. Spectra use a common dBFS scale, not separate peak normalization. The shaded region cannot be represented faithfully at 8 kHz.

In [4]:
def spectrum(samples, rate):
    segment = samples[int(.05 * rate):int(.55 * rate)]
    window = np.hanning(len(segment))
    amp = np.abs(np.fft.rfft(segment * window)) * 2 / window.sum()
    amp[0] /= 2
    if len(segment) % 2 == 0:
        amp[-1] /= 2
    return np.fft.rfftfreq(len(segment), 1 / rate), amp

def plot_audio(samples, rate, title, filename):
    freq, amp = spectrum(samples, rate)
    fig, axes = plt.subplots(2, 1, figsize=(10, 6), constrained_layout=True)
    time = np.arange(len(samples)) / rate
    axes[0].plot(time, samples, lw=.7)
    axes[0].set(xlabel="Time (s)", ylabel="Amplitude (FS)", ylim=(-1, 1), title=title)
    axes[1].plot(freq, 20 * np.log10(np.maximum(amp, 1e-8)), lw=.8)
    axes[1].set(xlabel="Frequency (Hz)", ylabel="Amplitude (dBFS)",
                xlim=(0, 12000 if rate == FS else 4000), ylim=(-110, 0))
    if rate == FS:
        axes[1].axvspan(4000, 12000, color="orange", alpha=.15, label="Above new Nyquist")
        axes[1].legend()
    axes[1].grid(alpha=.25)
    fig.savefig(OUT / filename, dpi=150)
    plt.show()

5. Low-pass first, then drop samples¶

A 513-tap Kaiser-window FIR, nominal cutoff 3.4 kHz, leaves a transition band before 4 kHz. We apply convolution before keeping every sixth sample. This removes much of the piano's original brightness, but avoids folding those upper harmonics into false lower frequencies.

For this offline comparison, centered convolution compensates the filter delay. A causal firmware implementation instead has 256/48000 seconds (5.33 ms) of delay and needs state across blocks. Boundary samples use zero padding; spectral verification excludes the boundaries.

In [5]:
h = firwin(513, 3400, fs=FS, window=("kaiser", 8.6))
low = np.convolve(x, h, mode="same")
filtered = save_wav(OUT / "piano_8khz_filtered.wav", low[::FACTOR], FS_OUT)
listen(filtered, FS_OUT)
plot_audio(filtered, FS_OUT, "Low-pass then sample dropping — 8 kHz", "piano_filtered.png")

6. Measure before drawing a conclusion¶

We measure windowed spectral energy above 4 kHz, relative to the total, and its reduction before decimation. This is a bandwidth-risk indicator, not a guarantee of audibility. It is not the same metric as the isolated 1 kHz alias in our three-tone experiment.

We also report the most prominent out-of-band spectral peak and its predicted folded frequency. Real piano harmonics are slightly inharmonic; folded components can overlap existing harmonics. A low-rate FFT alone cannot uniquely recover their original frequencies.

f, a = spectrum(x, FS)
_, low_a = spectrum(low, FS)
mask = f > FS_OUT / 2
energy_fraction = float(np.sum(a[mask]**2) / np.sum(a**2))
suppression = float(10*np.log10(np.sum(a[mask]**2) / np.sum(low_a[mask]**2)))
peak = float(f[np.flatnonzero(mask)[np.argmax(a[mask])]])
folded = float(abs((peak + FS_OUT/2) % FS_OUT - FS_OUT/2))
fundamental_mask = (f > 1600) & (f < 1900)
fundamental = float(f[np.flatnonzero(fundamental_mask)[np.argmax(a[fundamental_mask])]])

Future improvements: detecting risky bandwidth¶

  • Measure the energy above the target Nyquist limit on the high-rate input, as a first prototype.
  • Extend to short-time FFT/averaged PSD so the attack and decay are evaluated separately; a single long window can hide bursts.
  • Test notes at different pitches, velocities and recording noise floors. Choose a threshold with missed-event and false-alarm costs in mind.
  • Measure CPU cost and stream the FIR with persistent state on an MCU. Compare an efficient polyphase implementation.
  • Detection does not replace anti-alias filtering. Once only 8 kHz samples remain, their FFT cannot tell which components were originally above 4 kHz.

Listening is subjective. Filtering changes bandwidth and timbre intentionally; do not label every audible difference as aliasing. No ultrasonic test tone is injected into this piano recording.
